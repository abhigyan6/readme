### October 23, 2026 · Preserve valid falsy values with `??`

JavaScript's nullish coalescing operator (`??`) uses a fallback only for `null` or `undefined`. It preserves valid values such as `0`, an empty string, and `false`.

```javascript
const values = [0, "", false, null, undefined];
const result = values.map(value => value ?? "fallback");

console.log(result);
// [0, "", false, "fallback", "fallback"]
```

Use `??` for missing values. Use `||` when every falsy value should trigger the fallback.
