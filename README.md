### October 24, 2026 · Sort numbers without changing the original array

JavaScript's `sort()` compares values as strings by default and mutates the array. For ascending numeric order, provide a comparator. Copy the array first if you want to preserve the original.

```javascript
const scores = [10, 2, 30];
const ascending = [...scores].sort((a, b) => a - b);

console.log(ascending); // [2, 10, 30]
console.log(scores);    // [10, 2, 30]
```

A negative comparator result places `a` before `b`; a positive result places it after `b`. This example assumes finite numbers.
