### October 28, 2026 · Understand defaults in object destructuring

A destructuring default applies when a property is missing or `undefined`. It does not replace `null`, `0`, or `false`.

```javascript
function readLimit(options = {}) {
  const { limit = 10 } = options;
  return limit;
}

console.log(readLimit());                     // 10
console.log(readLimit({ limit: undefined })); // 10
console.log(readLimit({ limit: 0 }));         // 0
console.log(readLimit({ limit: null }));      // null
```

The parameter default `options = {}` handles an omitted or `undefined` argument. Passing `null` as the whole argument still throws a `TypeError` when destructuring.
