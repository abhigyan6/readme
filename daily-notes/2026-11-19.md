# Check an object's own property with Object.hasOwn

Date: 2026-11-19 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `Object.hasOwn(object, key)` to test whether a property belongs directly to an object. It still returns `true` when that property's value is `undefined`, unlike a value check.

```javascript
const user = { name: "Ari", role: undefined };

console.log(Object.hasOwn(user, "role"));  // true
console.log(Object.hasOwn(user, "email")); // false
```

This is useful when `undefined` is a meaningful explicitly supplied value or when objects may have inherited properties. It requires a JavaScript runtime that supports `Object.hasOwn()`.
