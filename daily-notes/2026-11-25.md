# Iterate Unicode code points with Array.from

Date: 2026-11-25 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Strings can contain characters represented by more than one UTF-16 code unit. `Array.from()` iterates string code points, so a basic emoji such as 🌱 stays together.

```javascript
const chars = Array.from("A🌱B");

console.log(chars);        // ["A", "🌱", "B"]
console.log(chars.length); // 3
```

This handles surrogate pairs, but some user-perceived characters (such as combined emoji or letters with separate accent marks) contain multiple code points. Use `Intl.Segmenter` when you need grapheme clusters.
