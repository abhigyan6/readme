# Validate numeric values with Number.isFinite

Date: 2026-11-27 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `Number.isFinite()` to accept only finite numbers. It does not coerce strings, so convert form input explicitly before checking it.

```javascript
const input = "19.99";
const amount = Number(input);

console.log(Number.isFinite(amount)); // true
console.log(Number.isFinite(input));  // false
console.log(Number.isFinite(Infinity)); // false
```

Invalid numeric text converts to `NaN`, which `Number.isFinite()` also rejects. This helps avoid accepting `NaN` or infinite values in calculations.
