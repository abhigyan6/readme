# Handle JSON parsing errors with try and catch

Date: 2026-11-10 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

`JSON.parse()` throws a `SyntaxError` when the input is malformed. Catch it at the boundary where data enters your app so invalid input can become a clear result.

```javascript
function parseJson(text) {
  try {
    return { ok: true, value: JSON.parse(text) };
  } catch (error) {
    if (error instanceof SyntaxError) return { ok: false };
    throw error; // preserve unexpected failures
  }
}

console.log(parseJson('{"active":true}')); // { ok: true, value: { active: true } }
console.log(parseJson('{broken'));          // { ok: false }
```

Keeping the `try` block focused on parsing makes it less likely that unrelated errors get mistaken for invalid JSON.
