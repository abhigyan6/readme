# Build an object from entries with Object.fromEntries

Date: 2026-11-28 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `Object.fromEntries()` to turn an iterable of key-value pairs into an object. If a key appears more than once, the last value is used.

```javascript
const entries = [
  ["theme", "dark"],
  ["density", "compact"],
  ["theme", "light"],
];

const settings = Object.fromEntries(entries);

console.log(settings); // { theme: "light", density: "compact" }
```

It creates a new object and leaves the source entries unchanged.
