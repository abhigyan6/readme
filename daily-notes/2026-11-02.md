# Turn simple CSV rows into typed records

Date: 2026-11-02 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

For a small, controlled CSV with no quoted commas, split each line into columns and convert numeric text explicitly. `split()` always returns strings, so a score needs `Number()` before numeric use.

```javascript
const csv = 'Ava,8\\nMia,12';
const records = csv.split('\\n').map(line => {
  const [name, score] = line.split(',');
  return { name, score: Number(score) };
});

console.log(records[1].score + 1); // 13
```

This compact approach assumes fields do not contain commas or embedded newlines; general CSV needs a parser that handles quoted fields.
