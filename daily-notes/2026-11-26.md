# Signal cancellation with AbortController

Date: 2026-11-26 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Create an `AbortController` and pass its `signal` to an API that supports cancellation, such as `fetch()`. Calling `abort()` marks the signal aborted and provides a reason.

```javascript
const controller = new AbortController();

controller.signal.addEventListener("abort", () => {
  console.log("Cancelled:", controller.signal.reason);
}, { once: true });

controller.abort("navigation changed");
```

The controller sends a cancellation signal; the operation must support and honor `AbortSignal` for its work to stop.
