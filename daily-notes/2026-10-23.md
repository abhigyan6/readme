# Preserve valid falsy values with `??`

Date: 2026-10-23 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

JavaScript's nullish coalescing operator (`??`) uses a fallback only when the value is `null` or `undefined`. It preserves valid values such as `0`, an empty string, and `false`.

```javascript
const values = [0, "", false, null, undefined];
const result = values.map(value => value ?? "fallback");

console.log(result);
// [0, "", false, "fallback", "fallback"]
```

Use `??` when a missing value needs a default. Use `||` only when every falsy value should trigger the fallback.
