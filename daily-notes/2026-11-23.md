# Replace every literal substring with replaceAll()

Date: 2026-11-23 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `String.prototype.replaceAll()` when every occurrence of a literal substring should change. Unlike `replace()` with a string search value, it replaces all matches.

```javascript
const colors = "red,red,blue";
const updated = colors.replaceAll("red", "green");

console.log(updated); // "green,green,blue"
console.log(colors);  // "red,red,blue"
```

Strings are immutable, so `replaceAll()` returns a new string and leaves the original unchanged. For regular-expression searches, the pattern must use the global `g` flag.
