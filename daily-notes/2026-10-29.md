# Find the first matching array element

Date: 2026-10-29 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `find()` to return the first element whose predicate passes. If nothing matches, it returns `undefined`.

```javascript
const tasks = [{ id: 1, done: false }, { id: 2, done: true }];
const completed = tasks.find(task => task.done);

console.log(completed?.id); // 2
console.log(tasks.find(task => task.id === 3)); // undefined
```

For objects, the result is a reference to the original element, not a copy. Editing it also changes that object in the array.
