# Check all or any elements with every and some

Date: 2026-10-27 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `every()` when all array elements must pass a test, and `some()` when at least one must pass. Both stop checking as soon as the answer is known.

```javascript
const scores = [72, 85, 91];

console.log(scores.every(score => score >= 60)); // true
console.log(scores.some(score => score >= 90));  // true

console.log([].every(score => score >= 60)); // true
console.log([].some(score => score >= 90));  // false
```

An empty array passes `every()` because no element fails the test. If you also require at least one entry, check `scores.length > 0 && scores.every(score => score >= 60)`.
