# Format currency with Intl.NumberFormat

Date: 2026-11-21 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `Intl.NumberFormat` to format numeric amounts for a locale and currency instead of assembling symbols and separators by hand.

```javascript
const inr = new Intl.NumberFormat("en-IN", {
  style: "currency",
  currency: "INR",
});

console.log(inr.format(12500)); // ₹12,500.00
```

The locale controls conventions such as grouping and decimal separators, while the ISO currency code controls the currency symbol and default fraction digits. Formatting can differ by runtime locale data.
