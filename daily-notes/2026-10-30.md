# Build query strings with URLSearchParams

Date: 2026-10-30 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `URLSearchParams` to encode query values instead of joining raw strings. Spaces become `+`, and the ampersand inside a value becomes `%26`.

```javascript
const params = new URLSearchParams();
params.set('q', 'UX & product design');
params.append('tag', 'web');
params.append('tag', 'ui');

console.log(params.toString());
// q=UX+%26+product+design&tag=web&tag=ui
```

Use `append()` for repeated keys and `getAll('tag')` to read all their values. Pass unencoded values to avoid encoding them twice; `toString()` returns the query without a leading `?`.
