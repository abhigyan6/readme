# Copy a Map before changing it

Date: 2026-11-04 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

`new Map(existingMap)` creates a separate map with the same entries. Updating the copy leaves the original collection unchanged.

```javascript
const roles = new Map([['designer', 'UX'], ['engineer', 'product']]);
const draft = new Map(roles);
draft.set('reviewer', 'quality');

console.log(roles.has('reviewer')); // false
console.log(draft.get('engineer')); // product
```

The copy is shallow: object values are still shared references. Use this pattern when you need an independent set of keys and values, and copy nested values separately if those must be independent too.
