# Use reduce with an explicit starting value

Date: 2026-11-05 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

`reduce()` combines array items into one result. Provide an initial value when empty input is possible so the result stays predictable.

```javascript
const sizes = [2, 3, 4];
const total = sizes.reduce((sum, size) => sum + size, 0);

console.log(total); // 9
console.log([].reduce((sum, size) => sum + size, 0)); // 0
```

Without an initial value, reducing an empty array throws a `TypeError`. The starting value also determines the accumulator's type, which is useful when building objects or strings.
