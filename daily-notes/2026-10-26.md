# Remove duplicate strings with Set

Date: 2026-10-26 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use a `Set` to remove duplicate strings while preserving their first-occurrence order. Spreading it into an array gives you a new array without changing the original.

```javascript
const tags = ['java', 'javascript', 'java', 'git'];
const uniqueTags = [...new Set(tags)];

console.log(uniqueTags); // ['java', 'javascript', 'git']
console.log(tags);       // ['java', 'javascript', 'java', 'git']
```

String matching is case-sensitive. Objects are compared by identity, so two separately created objects with the same properties remain separate entries.
