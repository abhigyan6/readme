# Make a deep copy of structured data with structuredClone

Date: 2026-11-18 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

For supported structured data, `structuredClone()` creates a deep copy so nested objects can be changed independently.

```javascript
const settings = { profile: { theme: 'dark' } };
const draft = structuredClone(settings);
draft.profile.theme = 'light';

console.log(settings.profile.theme); // 'dark'
console.log(draft.profile.theme);   // 'light'
```

It handles many built-in data types, including arrays, maps, sets, and dates. It cannot clone functions, and it throws for unsupported values; use it for data rather than arbitrary objects with behavior.
