# Collect every async outcome with Promise.allSettled

Date: 2026-11-20 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

Use `Promise.allSettled()` when every task should finish and you need to inspect both successes and failures. The returned results stay in the same order as the input promises.

```javascript
const results = await Promise.allSettled([
  Promise.resolve("profile"),
  Promise.reject(new Error("offline")),
]);

for (const result of results) {
  if (result.status === "fulfilled") {
    console.log("Loaded:", result.value);
  } else {
    console.log("Failed:", result.reason.message);
  }
}
```

Unlike `Promise.all()`, one rejected input does not reject the combined promise early; each result reports its own `status`.
