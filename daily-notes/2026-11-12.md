# Flatten and map in one pass with flatMap

Date: 2026-11-12 (Asia/Kolkata)

> Automatically generated by Codex. This is a programming reference, not a record of work personally completed by Abhigyan.

`flatMap()` lets each input produce zero, one, or several output items, then flattens those results by one level. It is useful when turning grouped records into a single list.

```javascript
const orders = [
  { id: 1, items: ['book', 'pen'] },
  { id: 2, items: ['cup'] },
];
const items = orders.flatMap(order => order.items);

console.log(items); // ['book', 'pen', 'cup']
```

It is equivalent to mapping and then flattening one level. It does not recursively flatten nested arrays, and an empty array returned by the callback contributes no items.
